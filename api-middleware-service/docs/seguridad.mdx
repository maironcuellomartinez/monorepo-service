## Validacion de entorno

<motion.div variants={sectionVariants} initial="hidden" whileInView="visible" viewport={{ once: true }}>
  <p>La funcion <code>requiredSecret()</code> en <code>configuration.ts</code> protege contra configuraciones inseguras:</p>
  <motion.pre variants={codeVariants} initial="hidden" whileInView="visible" viewport={{ once: true }} className="bg-muted p-4 rounded-lg overflow-x-auto">
    <code className="text-sm">{`function requiredSecret(key: string, fallback: string): string {
  const env = process.env.NODE_ENV ?? 'development';
  const value = process.env[key];

  if (env !== 'development') {
    if (!value) throw new Error(\`Variable '\${key}' no configurada\`);
    if (value.startsWith('dev-only--')) throw new Error(\`Variable '\${key}' tiene valor de desarrollo\`);
    return value;
  }

  return value ?? fallback;
}`}</code>
  </motion.pre>
  <p>Variables protegidas:</p>
  <ul className="list-disc pl-6">
    <li><code>JWT_SECRET</code></li>
    <li><code>ADMIN_SESSION_SECRET</code></li>
    <li><code>ABAC_M2M_TOKEN</code></li>
  </ul>
  <p>En staging/production, si alguna de estas variables falta o tiene el valor de desarrollo (<code>dev-only--...</code>), el servicio <strong>no arranca</strong>.</p>
</motion.div>

## Refresh token rotation

<motion.div variants={sectionVariants} initial="hidden" whileInView="visible" viewport={{ once: true }}>
  <p>Cada vez que se refresca un token:</p>
  <ol className="list-decimal pl-6 my-2">
    <li>Se verifica la firma JWT del refresh token</li>
    <li>Se busca en BD por hash del jti</li>
    <li>Se compara el hash con bcrypt</li>
  </ol>
  <p><strong>Si es valido:</strong></p>
  <ul className="list-disc pl-6">
    <li>Se revoca el token actual (<code>revokedAt = new Date()</code>)</li>
    <li>Se emite un nuevo access_token</li>
    <li>Se emite un nuevo refresh_token</li>
  </ul>
  <p><strong>Si el hash no coincide (reuse attack):</strong></p>
  <ul className="list-disc pl-6">
    <li>Se revocan TODOS los tokens del cliente</li>
    <li>Se responde con 401</li>
  </ul>
</motion.div>

## Sesion de administrador

<motion.div variants={sectionVariants} initial="hidden" whileInView="visible" viewport={{ once: true }}>
  <p>La sesion del dashboard se maneja con cookie httpOnly:</p>
  <motion.pre variants={codeVariants} initial="hidden" whileInView="visible" viewport={{ once: true }} className="bg-muted p-4 rounded-lg overflow-x-auto">
    <code className="text-sm">{`res.cookie('admin_session', token, {
  httpOnly: true,
  sameSite: 'strict',
  path: '/',
  secure: env !== 'development',  // solo HTTPS en prod
  maxAge: 24 * 60 * 60 * 1000,   // 24h
});`}</code>
  </motion.pre>
  <ul className="list-disc pl-6">
    <li><strong>httpOnly</strong>: no accesible desde JavaScript</li>
    <li><strong>sameSite: strict</strong>: no se envia en requests cross-site</li>
    <li><strong>secure</strong>: solo en HTTPS (excepto development)</li>
    <li><strong>maxAge</strong>: 24 horas</li>
  </ul>
</motion.div>

## Guards de autenticacion

<motion.div variants={sectionVariants} initial="hidden" whileInView="visible" viewport={{ once: true }}>
  <h3>AccessTokenGuard</h3>
  <p>Valida el JWT de cliente externo en endpoints de datos:</p>
  <motion.pre variants={codeVariants} className="bg-muted p-4 rounded-lg overflow-x-auto my-2">
    <code className="text-sm">{`const payload = this.jwt.verify(token, { secret });

  throw new UnauthorizedException('Token no pertenece a una aplicacion externa');
}`}</code>
  </motion.pre>

  <h3>AdminSessionGuard</h3>
  <p>Valida la cookie de sesion de administrador en endpoints de gestion:</p>
  <motion.pre variants={codeVariants} className="bg-muted p-4 rounded-lg overflow-x-auto my-2">
    <code className="text-sm">{`const payload = this.jwtService.verify(token);
(request as any).adminUser = { username: payload.username };`}</code>
  </motion.pre>

  <h3>AdminOrAccessGuard</h3>
  <p>Guard compuesto que acepta ambos metodos (usado en <code>/v1/requests/*</code>):</p>
  <ol className="list-decimal pl-6">
    <li>Intenta cookie de admin</li>
    <li>Si falla, intenta Bearer token de cliente externo</li>
    <li>Si ninguno es valido -> 401</li>
  </ol>

  <h3>OAuthBulkheadGuard</h3>
  <p>Protege <code>POST /oauth/token</code> contra abuso (ver <a href="./resiliencia.mdx">Resiliencia</a>).</p>
</motion.div>
