# API Middleware Service

> Proxy OAuth2 para aplicaciones externas hacia Event Corner (api-gateway interno).

---

## Descripcion

`api-middleware-service` es un servicio de autenticacion y autorizacion construido con **NestJS**. Actua como intermediario entre aplicaciones externas y el api-gateway interno. Implementa **OAuth2 client_credentials** con JWT local, gestion de clientes con bcrypt, y resiliencia en 3 niveles independientes.

<Alert>
  <AlertTitle>Sin base de datos de negocio</AlertTitle>
  <AlertDescription>
    El servicio solo gestiona clientes OAuth2, sesiones de administrador y refresh tokens. Los datos de solicitudes viven en el api-gateway interno — el middleware solo los consulta via proxy autenticado.
  </AlertDescription>
</Alert>

## Endpoints

### Autenticacion (`/oauth`)

| Metodo | Ruta | Auth | Descripcion |
|---|---|---|---|
| POST | `/oauth/token` | Basic Auth | Emitir access token (client_credentials) |
| POST | `/oauth/refresh` | — | Renovar access token via refresh token |

### Clientes (`/clients`)

| Metodo | Ruta | Auth | Descripcion |
|---|---|---|---|
| POST | `/clients` | AdminSession | Registrar aplicacion externa |
| GET | `/clients` | AdminSession | Listar aplicaciones |
| GET | `/clients/:clientId` | AdminSession | Detalle de aplicacion |
| PATCH | `/clients/:clientId/rotate-secret` | AdminSession | Rotar client_secret |
| PATCH | `/clients/:clientId/token-expiry` | AdminSession | Actualizar duracion del token |
| DELETE | `/clients/:clientId` | AdminSession | Desactivar aplicacion |

### Records (`/v1`)

| Metodo | Ruta | Auth | Descripcion |
|---|---|---|---|
| GET | `/v1/requests/:number` | Bearer o AdminSession | Solicitud por numero |
| GET | `/v1/requests` | Bearer o AdminSession | Listar solicitudes con filtros |

### Admin (`/admin`)

| Metodo | Ruta | Auth | Descripcion |
|---|---|---|---|
| GET | `/admin/setup-required` | — | Verificar si necesita configuracion inicial |
| POST | `/admin/setup` | — | Crear primer administrador |
| POST | `/admin/login` | — | Iniciar sesion |
| POST | `/admin/logout` | — | Cerrar sesion |
| GET | `/admin/me` | AdminSession | Usuario autenticado |

  Note over App,DB: Registro inicial (solo admin)

  Note over App,DB: Emision de token
  App->>MW: POST /oauth/token con Basic Auth
  MW->>DB: SELECT client WHERE clientId match
  MW->>MW: bcrypt.compare(secret, hash)
  MW->>DB: INSERT refresh_token con bcrypt del jti
  MW-->>App: access_token + refresh_token + expires_in

  Note over App,DB: Acceso a datos
  App->>MW: GET /v1/requests con Bearer token
  MW->>MW: jwt.verify con JWT_SECRET
  MW->>MW: GatewayClient bulkhead + circuit breaker
  MW-->>App: datos del api-gateway
`} />

## Capa de resiliencia

### Nivel 1 — HTTP Bulkhead entrante

Middleware que limita requests concurrentes entrantes (default: 50 concurrencia, 100 cola). Excluye `/health/status`.

### Nivel 2 — OAuth Bulkhead

Guard especifico para `POST /oauth/token` que limita a **3 bcrypt simultaneos** (max 5 en cola, timeout 5s). Protege contra fuerza bruta y DoS via CPU exhaustion.

### Nivel 3 — Gateway saliente

- **PQueue**: dos colas de prioridad (HP concurrencia 10, LP concurrencia 5)
- **Circuit Breaker** (opossum): se abre si >50% errores 5xx en ventana de 5 llamadas, reset a los 30s

## Entidades de base de datos

### external_clients

| Columna | Tipo | Descripcion |
|---|---|---|
| clientId | VARCHAR(64) PK | ID con prefijo `mc_` |
| clientSecretHash | VARCHAR(128) | bcrypt del secret |
| name | VARCHAR(100) | Nombre de la app |
| description | VARCHAR(255) | Descripcion opcional |
| tokenExpiresInSeconds | INT | Duracion del token (3600–604800) |
| isActive | BOOLEAN | Si esta activo |
| createdAt | DATETIME | Fecha de creacion |
| updatedAt | DATETIME | Ultima actualizacion |

### refresh_tokens

| Columna | Tipo | Descripcion |
|---|---|---|
| id | INT PK | Auto-increment |
| clientId | VARCHAR(64) | Cliente asociado |
| tokenHash | VARCHAR(128) | bcrypt del jti del refresh token |
| expiresAt | DATETIME | Fecha de expiracion (7 dias fijos) |
| revokedAt | DATETIME | Fecha de revocacion (nullable) |
| createdAt | DATETIME | Fecha de creacion |

### admins

| Columna | Tipo | Descripcion |
|---|---|---|
| id | INT PK | Auto-increment |
| username | VARCHAR(100) | Nombre de usuario |
| passwordHash | VARCHAR(128) | bcrypt de la contrasena |
| createdAt | DATETIME | Fecha de creacion |
