  Paso 3 — construir dev token y llamar /api/auth/me

  En PowerShell:
  $payload = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes('{"oid":"oid-test-usuario-001","email":"juan.perez@empresa.com"
  ,"name":"Juan Perez"}'))
  $payload = $payload.Replace('+','-').Replace('/','_').TrimEnd('=')
  $token = "dev:$payload"

  curl -s http://localhost:3000/api/auth/me -H "Authorization: Bearer $token"

  En bash (Git Bash / WSL):
  PAYLOAD=$(printf '{"oid":"oid-test-usuario-001","email":"juan.perez@empresa.com","name":"Juan Perez"}' | base64 | tr '+/' '-_' | tr
   -d '=')
  curl -s http://localhost:3000/api/auth/me -H "Authorization: Bearer dev:${PAYLOAD}"

  De la respuesta copiás el campo monolithUserId.

  Paso 5 — sync y verificación (necesitás el dev token del paso 3)

  # Poblar DB local del monolith
  curl -s -X POST http://localhost:3000/api/devices/sync-user/<monolithUserId> \
    -H "Authorization: Bearer dev:<PAYLOAD>"

  # Verificar que quedaron en la DB local
  curl -s "http://localhost:3000/api/devices?userId=<monolithUserId>" \
    -H "Authorization: Bearer dev:<PAYLOAD>"
