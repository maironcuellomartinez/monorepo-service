Aquí está la secuencia completa para crear el usuario admin:

  Paso 1 — Obtener JWT del super-admin:
  curl -s -X POST http://localhost:3005/auth/admin/login \
    -H "Content-Type: application/json" \
    -d '{"email":"superadmin@abac.com","password":"superadmin"}' | jq -r '.accessToken'

  Guarda ese token y úsalo en los siguientes pasos (reemplaza <TOKEN>):

  Paso 2 — Crear el usuario admin:
  curl -s -X POST http://localhost:3005/users \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer <TOKEN>" \
    -d '{
      "email": "admin@eventcorner.com",
      "password": "Admin1234!",
      "firstName": "Admin",
      "lastName": "EventCorner",
      "username": "admin"
    }' | jq .

  Copia el id del usuario creado y úsalo como <USER_ID>:

  Paso 3 — Asignar rol admin:
  curl -s -X POST http://localhost:3005/users/<USER_ID>/roles \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer <TOKEN>" \
    -d '{
      "roleId": "3355ba3c-1fbc-4ea0-8f74-27a8cbd82e05",
      "applicationId": "df959358-c1c0-477a-8a6d-133451d1cd10"
    }' | jq .

  O si prefieres hacerlo todo en un script de una vez en bash:

  TOKEN=$(curl -s -X POST http://localhost:3005/auth/admin/login \
    -H "Content-Type: application/json" \
    -d '{"email":"superadmin@abac.com","password":"superadmin"}' | jq -r '.accessToken')

  echo "Token: $TOKEN"

  USER_ID=$(curl -s -X POST http://localhost:3005/users \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $TOKEN" \
    -d '{
      "email": "admin@eventcorner.com",
      "password": "Admin1234!",
      "firstName": "Admin",
      "lastName": "EventCorner",
      "username": "admin"
    }' | jq -r '.id')

  echo "User ID: $USER_ID"

  curl -s -X POST http://localhost:3005/users/$USER_ID/roles \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $TOKEN" \
    -d '{
      "roleId": "3355ba3c-1fbc-4ea0-8f74-27a8cbd82e05",
      "applicationId": "df959358-c1c0-477a-8a6d-133451d1cd10"
    }' | jq .

  Puedes ejecutarlo desde la terminal con ! <script> o directamente en bash. El usuario resultante podrá hacer login en el Event
  Corner app con admin@eventcorner.com / Admin1234!.
